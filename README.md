# AuraBeat · 音乐可视化器 🎵✨

把音乐变成一片流动的光。纯前端 3D 音乐可视化器，基于 Three.js + Web Audio API。

## 功能

- 🎵 **本地音乐**：点击选择或直接拖拽音频文件进页面
- 🎤 **麦克风实时输入**：对着麦克风唱歌/说话，画面实时反应
- ▶️ **内置演示曲**：程序合成的 32 秒电子乐（Neon Drive），零外部文件
- 🎨 **三套配色主题**：霓虹紫 / 火焰橙 / 冰蓝
- 📷 **截图导出**：一键保存当前画面 PNG
- ⚡ **自动性能检测**：低帧率时自动降低粒子密度
- 🎚 **灵敏度 / 光晕调节** + 自由相机（拖拽旋转 + 自动运镜）

## 技术

- **Vite** — 构建与开发服务器
- **Three.js** — 3D 粒子舞台（6000 粒子 + 节拍冲击波环 + 环形光带）
- **Web Audio API** — 频谱分析（FFT 256）与能量分频（低频/中频/高频）
- **节拍检测** — 低频能量突增 + 自适应阈值 + 冷却时间

## 快速开始

```bash
npm install
npm run dev     # 开发
npm run build   # 构建到 dist/
```
